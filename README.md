# Presentation Tool

A Java desktop editor for presentations, designed and implemented as an extensive software engineering assignment, targeting its ability to show off the application of SOLID principles, MVC, and other primary design patterns.


## About

In this project, rather than focusing solely on implementing all the features or achieving full graphical accuracy comparable to commercial applications like PowerPoint, there was an aim to produce a clean, simple, and well-structured code which presents fundamental concepts in software engineering. Greatest emphasis is given to separating concerns among data layers, functional logic, and user interface, while at the same time implementing several creative structural, and behavioral patterns.

## Features

- **Presentation management** - Create, open, save and "Save As" presentation projects
- **Slide operations** - Add, remove and reorder slides within a presentation
- **Content editing** - Inserting and adjusting text and visual content on slides
- **Undo / Redo** - Ability to undo and redo actions in the editing process
- **Templates** - Creating reusable templates and implementation in new or active projects

## Architecture & Design

The project architecture follows the **MVC (Model-View-Controller)** pattern and adheres to **SOLID** principles in software development.

## Getting Started

### Prerequisites

- Java 20 or newer
- Any Java IDE (IntelliJ IDEA, Eclipse, etc.) or command line

### Running the application

```bash
git clone https://github.com/your-username/presentation-tool.git
cd presentation-tool
javac -d out src/**/*.java
java -cp out Main
```

> It is necessary to match the above commands with the specific structure of the project and the used automation tools (Maven, Gradle, etc.).
